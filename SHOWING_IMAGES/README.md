# Displaying animated gifs


Link to P5.js web editor code that saves frames from an animated GIF to show on a 128 x 64 one color OLED. It ouputs all the code you need which you can copy into the arduino code shared in this folder, by pasting it into the animation.h file. [P5 Web Editor code](https://editor.p5js.org/peteRogers/sketches/XGzKP9Yvm)

A newer, in-browser version of the same idea lives in this repo as [`GIF_2_OLED_MAKER`](GIF_2_OLED_MAKER) - drop in any animated GIF and it converts it straight into the Arduino code/array data needed to play it back on the OLED, no separate editor needed. Try it live: [GIF to OLED Converter](https://peterogers.github.io/OLED_Displays/SHOWING_IMAGES/GIF_2_OLED_MAKER/)
